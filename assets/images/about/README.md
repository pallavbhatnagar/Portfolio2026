# About page photos

The About page carousel shows drawn icons until you add photos here.

1. Save your photos in this folder as `photo-1.jpg` to `photo-9.jpg`
   (portrait, about 4:5, around 800 × 1000 px).
2. In `about.html`, each carousel slide has a comment like
   `<!-- Replace the icon with your photo: <img src="assets/images/about/photo-1.jpg" ...> -->`.
   Replace that slide's icon with the `<img>` from its comment.

Optional:
- `friend-1.jpg` and so on: photos for the "Teammates I'd work with again" avatars (see the comment in `about.html`).
- `name.jpg`: a photo for the Home page (see the comment in `index.html`).
