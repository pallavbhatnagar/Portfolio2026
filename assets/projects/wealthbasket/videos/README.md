# wealthbasket videos

The original two videos (the WealthBasket introduction and the Paytm Money
campaign film) were on Vimeo (605510281 and 605509955) and are no longer
available there. If you still have the files, put them here as:

- `introduction.mp4`  (shown on the cover; poster: images/cover.jpg)
- `campaign.mp4`      (shown under "Looking back"; poster: images/campaign.jpg)

Use MP4 (H.264), each under about 10 MB. The case study page
(work/wealthbasket.html) has a comment at each spot showing the one line
to change so the video plays instead of the still image.
