# wealthbasket: images to replace

These are placeholders that look like the site's drawn badges. Replace any of
them with the real thing, keeping the same file name, and the case study
(work/wealthbasket.html) picks it up. No code changes needed.

## team/ (people on the project, shown as overlapping circles)
- `team/design-lead.png`
- `team/ux-researcher.png`
- `team/paytm-money-product-team.png`

Use a square photo, at least 128 x 128 px. It's cropped to a circle
automatically. Any image works if you save it with the .png name above
(a JPG renamed to .png is fine).

## tools/ (logos next to "Tools used")
- `tools/adobe-xd.png`
- `tools/sketch.png`
- `tools/asana.png`

Use a square logo, at least 96 x 96 px, ideally the app's icon on its own
background. Shown at about 26 px with slightly rounded corners.

## Adding or removing someone or a tool
Edit the "The team" or "Tools used" list in work/wealthbasket.html: copy an
existing <li> line and point it at your new file.
