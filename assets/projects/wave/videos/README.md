# wave videos

Put this project's videos here: screen recordings, prototype walkthroughs
or motion studies. Name them in lowercase with hyphens, for example:

- `walkthrough.mp4`
- `prototype-onboarding.mp4`
- `detail-01.mp4`

Use MP4 (H.264) and keep each file under about 10 MB so the page stays fast.
A video only shows on the site once a page is set up to use it; ask for it to
be added to this project's case study.
